# Боты астрономического портала

Оба бота используют один RAG API (`POST /api/v1/assistant/answer`). В личном чате отвечают на текстовые вопросы, отправляют до трёх иллюстраций из использованных материалов и ссылки на источники. Команды `/start` и `/help` показывают приветствие. Изображения загружаются из RAG, конвертируются в PNG и передаются в мессенджер; токены мессенджеров остаются только в переменных окружения.

В корневом `.env` задайте `TELEGRAM_BOT_TOKEN`, `MAX_BOT_TOKEN`, публичный HTTPS-адрес `PORTAL_PUBLIC_URL`, `MAX_WEBHOOK_URL=https://ваш-домен/webhooks/max` и случайный `MAX_WEBHOOK_SECRET` (5–256 символов `A-Z`, `a-z`, `0-9`, `_`, `-`). Затем:

```sh
docker compose --profile telegram --profile max up --build -d
```

Для запуска одного бота оставьте один профиль. Без профилей боты не стартуют. RAG-ключ LLM настраивается отдельно (`ASSISTANT_PROVIDER` и ключ провайдера).

MAX регистрирует webhook через `POST /subscriptions` при запуске. Gateway передаёт `/webhooks/max` сервису бота; внешний HTTPS-прокси должен направлять этот путь на gateway, слушая порт 443 с доверенным сертификатом. Входящие события проверяются по `X-Max-Bot-Api-Secret` и сохраняются в отдельном томе SQLite до обработки. Telegram использует long polling и требует отключённый webhook при работе через `getUpdates`.
