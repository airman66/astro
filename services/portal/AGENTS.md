# Правила для `portal`

## Назначение

Единственный фронтенд портала «Параллакс»: рейтинг кандидатов NASA, карточки планет, методика, сравнение, справочник, поиск, помощник и раздел экспериментов (задача трёх тел, учебный опыт с потоком). Отдельные сайты не создавать: новые интерактивы добавляются страницами `src/pages` или `src/experiments`.

## Стек и сборка

Preact 11, TypeScript 7, Vite 8, модули D3 (`d3-scale`, `d3-array`, `d3-shape`, `d3-format`, `d3-quadtree`), шрифты Piazzolla и Golos Text из Fontsource (без внешних CDN). `npm ci`, `npm run build` (проверка типов и сборка), `npm test` (Vitest: численные проверки задачи трёх тел). В Docker сборка и тесты идут в `Dockerfile`, статику отдаёт nginx с SPA-фолбэком (`nginx.conf`), gateway проксирует `/` в сервис `portal`.

Разработка: запустить стек (`docker compose up -d` в корне), затем `npm run dev` — Vite проксирует `/api` и `/health` на `http://localhost:8090` (`GATEWAY_URL` меняет адрес).

## Данные и честность

- Только относительные URL того же origin: `/api/...`, `/api/v1/...`. Ключи и секреты во фронтенд не попадают.
- Обрабатывать `ready: false` и `503` до первой загрузки NASA (ожидание с автоповтором), `429` с `Retry-After`, `503 assistant_unavailable` (причина из `message`), `502/504` помощника. Справочник и поиск работают без помощника.
- Балл — сортировочная эвристика, не вероятность жизни, не ESI. TSM/ESM и HWC показываются отдельно и в балл не входят. Значения выводить с единицами и происхождением (опубликовано, вычислено архивом, вычислено нами); пропуски показывать, а не прятать.
- Ничего не выдумывать: числа на графиках — только из API. Иллюстрации нейросети подписываются как иллюстрации, не как наблюдения.

## Визуальный язык

Научно-редакционный: Piazzolla для заголовков и текста, Golos Text для интерфейса и чисел; нейтральная бумага и тёмно-синие чернила, зелёные полосы зоны обитаемости как главный цветовой акцент. Не использовать фиолетовые градиенты, стекло, неоновое свечение, россыпи одинаковых карточек, декоративные звёзды и конструкции вида «слово.слово» в названиях и заголовках. Цвета данных — проверенная палитра (`src/styles/tokens.css`), у каждого графика легенда, подписи единиц, описание выборки в подписи и табличная альтернатива. Обязательны мобильная вёрстка, управление с клавиатуры, видимый фокус и `prefers-reduced-motion`.
