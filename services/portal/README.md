# Портал «Алкиона» — фронтенд

Единый интерфейс портала: рейтинг кандидатов NASA с визуализациями, карточки планет, сравнение, методика, справочник по астрономии, поиск, помощник и эксперименты (задача трёх тел, опыт с потоком излучения).

```sh
npm ci
npm run dev      # http://localhost:5173, API проксируется на gateway http://localhost:8090
npm run build    # проверка типов и сборка в dist/
npm test         # численные проверки задачи трёх тел (Vitest)
```

В Docker образ собирает статику и запускает тесты, nginx отдаёт `dist/` с SPA-фолбэком; gateway проксирует на него `/`. Все запросы к API — относительные пути того же origin.

Структура: `src/pages` — страницы, `src/charts` — графики (canvas для тысяч точек, SVG для осей и подписей, подсказки и навигация с клавиатуры), `src/api` — контракт и клиент, `src/lib` — форматирование, научные подписи, хуки, `src/experiments/threebody` — физика и интерфейс задачи трёх тел, `src/styles` — токены и стили. Правила — `AGENTS.md`, сторонний код и лицензии — `THIRD_PARTY_NOTICES.md`.
