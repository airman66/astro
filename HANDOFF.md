# Передача работы: портал «Параллакс»

Что сделано в этом пакете, как запустить и что осталось. Подробности — в `README.md`, контракт — в `docs/API.md`.

## Как запустить у себя

1. Docker и Docker Compose (на Windows — Docker Desktop или Docker Engine в WSL 2).
2. `cp .env.example .env`, вписать свой `DEEPSEEK_API_KEY`, сгенерировать `SESSION_SECRET` (`openssl rand -hex 32`). Ключи в архиве не передаются.
3. `docker compose up --build -d` — первый запуск скачает модель эмбеддингов (4,7 ГБ). С видеокартой NVIDIA: `docker compose -f compose.yaml -f compose.gpu.yaml up -d`.
4. Оригиналы изображений Astro4Edu (1,5 ГБ) в архив не входят, их восстанавливает импорт с проверкой SHA-256: `docker compose run --rm --no-deps glossary-rag python -m app.importer --media-only --workers 4`. Без них часть медиа в справочнике показывает аккуратную заглушку со ссылкой на источник.
5. `python3 scripts/smoke.py` — сквозная проверка, затем откройте `http://localhost:8090`.

## Что сделано

- **Новый фронтенд** `services/portal` (Preact, TypeScript, Vite, D3), отдаётся по `/` через gateway:
  - главная — диаграмма «поток × температура звезды» по всему каталогу NASA с зонами Kopparapu, рейтинг, воронка отбора, размер и масса против потока, устойчивость места, распределение баллов, карта неба;
  - карточка планеты — состав балла, исходные величины с происхождением, пропуски, устойчивость, TSM/ESM, HWC, наблюдения Gaia/TESS/спектров, схема орбиты в масштабе;
  - сравнение, методика, справочник с алфавитом и поиском, помощник, эксперименты (задача трёх тел, опыт с потоком).
  Прежний PoC сохранён в `services/planets-api/Planets.Api/wwwroot`.
- **Бэкенд**: исправлены ошибки из ревью, у каждой есть тест или проверка. Перечень — в разделе «Найденные и исправленные ошибки».
- **Переводы**: проверены все 16 602 переводимых поля всех 501 записи (2784 уникальные пары EN/RU). Исправлено 1135 полей: кальки 695, грамматика 403, искажения смысла 345, терминология 299, числа 126. Из них 324 исправления подтверждены независимой моделью, 811 применены без неё по решению заказчика и помечены в отчёте. Спорных мест 675, замечаний к английскому оригиналу 511. Отчёт по каждому ID — `services/glossary-rag/data/eval/translation_audit/`.
- **Иллюстрации**: манифест 501 термина с индивидуальными промптами, alt-текстами и подписями, задание для ChatGPT, 21 пакет на 4 потока, возобновляемая очередь, импорт и проверка покрытия (`services/glossary-rag/data/illustrations/`). Пилот: 3 иллюстрации сгенерированы через ChatGPT (Codex CLI) и показываются в портале со статусом `generated`, ждут просмотра человеком.

## Что осталось и от чего зависит

- **Иллюстрации.** Готовы 3 из 501. Остальные 498 генерируются одной командой: `python -m scripts.illustrations run --workers 4` (через Codex CLI на аккаунте ChatGPT, около 80 секунд на картинку) или вручную в ChatGPT по пакетам `data/illustrations/batches/` с последующим `import`. Очередь продолжает с места остановки и не повторяет готовое. Пока картинки нет, портал показывает пустое состояние. Перед публикацией редактор ставит `approved` или `rejected`.
- **Переводы.** Автоматическое ревью закончено, но не заменяет редактора: все записи остаются `draft`. 675 спорных мест и 511 замечаний к оригиналу перечислены в `report.json` и `summary.md`.
- **Помощник.** На аккаунте DeepSeek, ключ которого использовался, закончился баланс (ушёл на ревью переводов). Пока баланс не пополнен, помощник отвечает `503 assistant_unavailable` с этой причиной, а ответы на контрольные вопросы проверить нельзя. Поиск по справочнику проверен: Recall@5 = 1,0, MRR = 0,974 на 50 контрольных вопросах.
